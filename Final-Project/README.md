# 📘 Computerized University Examination System

## 📌 Project Overview
This project is a computerized examination system that simulates a real online MCQ-based test environment. It allows users to log in, attempt multiple-choice questions, and automatically generates results with subject-wise analysis and file saving.

---

## ✨ Features
- 🔐 User Login (Roll Number & Password)
- ❓ Multiple Choice Questions (MCQs)
- ⏱️ Timer for each question
- 🔀 Random question order (shuffling)
- 📊 Subject-wise performance tracking
- 🧮 Automatic scoring system
- 📄 Final result display
- 💾 Result saved in a text file
- 🖥️ Windows GUI using Win32 API

---

## 🧠 Subjects Included
- Advanced Mathematics
- Mathematics
- English

---

## ⚙️ How the System Works
1. User enters Roll Number and Password
2. System verifies login (basic validation)
3. Exam starts automatically
4. Each question appears with 4 options
5. Timer runs for each question
6. User selects an answer
7. Score updates in real-time
8. After completion, final result is shown
9. Result is also saved in a `.txt` file
